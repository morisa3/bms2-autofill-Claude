# 主程式：掃描＋核對、填寫、比對資料輸出（第 5 步）

雙擊 **`填報助手.bat`** 開啟。掃描、核對、比對輸出都是唯讀；只有在「② 送出資料」「③ 送出檢測員意見」「④ 上傳基本照片」按下送出並確認後，才會修改網站資料。

## 畫面

| 區塊 | 內容 |
|---|---|
| 上方 | 橋名（輸入後將自動進行掃描）、**開始**、**歷史紀錄**、**網站：本期**（皆為下拉選單）、**隱藏網站**、開啟判讀結果資料夾、停止；最右邊「其他功能」選單 |
| 左側 | 內嵌網站（沿用登入狀態），分前期、本期兩個面板，網頁縮放依網站面板寬度自動調整（60%～100%；面板約 730 像素時為 85%），換螢幕解析度、拖動分隔線或切換單／雙網站都會自動適配，第一級、第二級與主頁面不必左右拖動。程式開啟時視窗自動放到最大。預設只顯示本期 |
| 右側「① 核對與修改」 | 上方數字卡片（待處理、可送出、已送出、送出異常、無需修改、全部，點了就篩選）＋**一張缺失清單**（狀態合併審查與填寫，以底色表示）＋工作區（判定、修改本期、填寫狀態）。只做核對與修改，不送出網站。工具列左側：本期照片、前期照片、前後期照片比對、回到缺失主頁面；右側：工作區放右側／下方、重新掃描本期、重新整理、進階篩選 |
| 右側「② 送出資料」 | 所有要送出／已送出的變更與結果，可整批或單筆送出（雙擊一列回到 ① 修改） |
| 右側「③ 送出檢測員意見」 | 檢測員意見與檢測基本資料 |
| 右側「④ 上傳基本照片」 | 橋梁照片簿的六張照片 |
| 右側「⑤ 比對資料輸出」 | 「輸出比對 Excel」：配對與審查結果存到「判讀結果」資料夾 |
| 右側下方「紀錄」 | 掃描過程與核對異常；與上方步驟之間可拖拉調整高度；點「紀錄」可收合（設定會記住） |

**缺失清單的欄位**：構件、編號、前期備註、本期備註、判定、信心、理由（工作區放右側時，優先看得到構件、編號與前後期備註）。捲動一次一列。狀態不另列一欄，以底色區分（滑鼠停在任一格會顯示狀態與說明）；
將填寫的變更看「② 送出」。每列固定兩行高（構件名稱較長時也折成兩行），欄寬依最寬的內容自動調整（長文字欄有上限，完整內容看滑鼠提示或工作區）。
「其他」構件只寫「其他」，設施類別（鋪面等）在編號欄。備註的位置與樣態尺寸分兩行（例：A1-L,R／土石堆積、A2／AC剝落(20m*9m)）。

**編號**簡化成代碼（橋頭＝A1、橋尾＝A2），② 送出清單與工作區標題也相同：

| 構件 | 網站欄位 | 編號 |
|---|---|---|
| 引道路堤（護欄、保護措施） | 位置：橋頭／橋尾 | A1／A2 |
| 伸縮縫、支承 | 位置：橋台(A)、橋墩(P)＋編號 | A1、P3、A2 |
| 墩柱與帽梁 | 橋墩編號 P002、編號 P02N-1 | P2/P02N-1 |
| 主梁 | 橋孔 S003、編號 S3G1 | S3/G1 |
| 橋面板 | 橋孔 S004、編號 S4 | S4 |
| 其他 | 設施類別（設施編號無意義，不顯示） | 鋪面 |
| 拱肋（拱圈） | 橋孔 S003、拱圈編號 R01-1 | S3/R01-1 |
| 立柱 | 橋孔 S001、拱圈 R01-1、立柱 R01-1H01 | S1/R01-1H01 |
| 斜撐 | 橋孔 S001 | S1 |
| 橫桿 | 橋孔 S001、橫桿編號 R01-B01 | S1/R01-B01 |

**工作區**：最上方是標題與「修改本期」，下一列是判定、改配對、上一筆、下一筆、只在待處理之間移動、確認並下一筆；再下面是前期與本期兩欄。
按「修改本期」時，本期欄**直接換成修改欄位**（不另開一欄），下方出現 Excel 規則、樣態按鈕與導入前期、確認維持現值、帶入程式建議、還原網站值、儲存修改。
判定不再有說明欄（舊審查檔的說明照舊保留在比對 Excel）。

**1080p 螢幕**：修改本期時工作區不需捲動（下方或右側都一樣）。螢幕較矮時按「工作區放右側」，清單與工作區左右並排
（建議搭配「隱藏網站」），捲動清單不必再縮小工作區；再按「工作區放下方」恢復。這個設定和紀錄收合都會記住。

「顯示完整網頁／精簡網頁」：預設精簡網頁——隱藏網站標題列與選單、檢測人員與檢測開始／結束照片（也不下載這些照片）、檢測路徑、3D 動態生成與輸出 Word 按鈕；構件列表收成左上角「構件列表」按鈕，點了才展開、點選構件後自動收合。只改畫面，表單欄位照常存在與送出，掃描與填寫不受影響；需要用到被隱藏的功能（例如上傳檢測人員照片）時按「顯示完整網頁」。第二級缺失頁的損壞照片照常顯示。

右下角狀態列顯示目前的網頁縮放比例（例：網頁縮放：本期 85%｜前期 85%）。

「網站」按鈕上寫目前選的顯示方式（網站：本期／前期／前期＋本期），點開選單切換。網站區預設寬度：兩個網站並排時約佔 73%、只顯示一個時約 58%，但每個網站最多給到網頁 100% 縮放所需的寬度（約 900 像素），
多出的空間給工作區——4K 等大螢幕網站不會留白、工作區變寬。拖動網站與工作區之間的分隔線後，程式會記住各顯示方式（本期／前期／並排）的比例，下次沿用。
「隱藏網站」按一下全部隱藏（審查區放大），變成「顯示網站」；再按一下依目前選的方式恢復（例如前期＋本期就兩個都開）。

「歷史紀錄」列出之前掃描過的橋（新到舊），顯示本期日期、待審查與已修改筆數、最後更新時間；點一筆直接接續審查與修改，不必重新掃描。
輸入的橋名若已有掃描紀錄，按「開始」會先問「接續上次」或「重新掃描」（網站資料有變動時才需要重新掃描）。
選單最下方「清除歷史紀錄…」：勾選要清除的紀錄（可全選），確認後刪除本期／前期掃描檔、審查與修改、填寫進度；只刪本機紀錄，不影響網站，「判讀結果」的比對 Excel 不刪。

「其他功能」選單：定期檢測查詢、基本資料搜尋（把左側網站帶到該頁）、掃描目前頁面（左側開著的缺失主頁面，例如要處理的不是最新一期時）、開啟掃描檔…、開啟暫存資料夾。

**清單的狀態（審查＋填寫合併）**

| 狀態 | 意思 |
|---|---|
| 待處理 | 審查待確認，或填寫需確認（理由欄寫明是哪一種） |
| 可送出 | 已確認，且有要填寫到網站的變更（理由欄與「② 送出」列出） |
| 已送出 | 已送出並回讀核對一致 |
| 送出異常 | 送出結果不明（待確認）或沒有送出（失敗） |
| 無需修改 | 網站已符合、不需填寫（含確認維持現值），或只有前期（漏建、已維修等） |

開啟或掃描完成時自動顯示「待處理」並打開第一筆；點選清單任一筆，下方工作區直接顯示，不換頁。「確認並下一筆」只在待處理之間移動，全部處理完提示可以整批送出。

## 步驟

1. 開啟後先在左側網站**登入**（之後會記住登入狀態）。
2. 在上方「橋名」輸入橋名，按「**開始**」（或按 Enter）。程式自動：
   - 用網站的「定期檢測 → 進階查詢」查詢橋名；
   - 查到**多座相似的橋**（例如龍門大橋、龍門大橋(2)），或橋名不完全相同時，跳出清單請你選擇（顯示橋梁系統ID、管理機關、所在地、最新檢測日期）；只有一座且同名時直接處理；
   - 左側開啟該橋的**基本資料**，上方出現黃色確認列；捲動網站確認沒有選錯橋後按「是這座橋，開始掃描」（「不是，取消」則不掃描）；
   - 由歷史定期檢測紀錄取最新一期為**本期**、前一期為**前期**，左側網站同步開到本期缺失主頁面；
   - **網站上還沒有本年度的檢測紀錄**時（確認列會先提示）：先把最新一期當作**前期**掃描建檔，再重新讀取歷史紀錄——
     有本年度紀錄就接著掃描本期並配對；沒有就停下來，跳出「前期已建檔」說明，本期先不掃描。
     之後在網站新增本年度紀錄、填好缺失，再輸入橋名按「開始」，程式**沿用已建檔的前期（不重新掃描）**，只掃描本期；
   - 唯讀掃描本期、前期、基本資料，完成前後期配對。
3. **① 掃描＋核對**：上方顯示「待審查 n」。篩選「待審查」或到「逐筆審查」（預設只在待審查之間移動）逐筆處理；
   最後一筆處理完會從頭找還沒審查的，全部審查完自動回到總表。
   審查結果自動存到 `temp/review/`；下次從「其他功能 → 開啟掃描檔…」選同一期的 `*-檢測.json`，可接續審查，不必重新掃描。
4. **② 送出資料**：見下方「填寫網站」；③ 檢測員意見、④ 基本照片見後面各節。
5. **③ 比對資料輸出**：按「輸出比對 Excel」，檔案存到 `判讀結果/日期-橋名-前後期比對.xlsx`；
   「全部配對」工作表一定輸出（含程式判定、最終判定、審查說明、修改內容），另可勾選「U值增減」「新增劣化」「未建（漏建）劣化」各一張工作表。
   上方「開啟判讀結果資料夾」直接開啟該資料夾。Excel 開著時無法覆寫，請先關閉。
   這份 Excel 是給人看的紀錄（核對下包資料、留存、回報），**填寫不讀這份 Excel**：第 6 步直接使用審查檔中的判定與修改。

## 逐筆審查：照片與修改

- **本期照片**：本期網站開到這筆的第二級**編輯頁**並捲到「損壞照片」，要刪照片直接在頁面上刪。
- **前期照片**：前期網站開到前期這筆的第二級**檢視頁**。
- **前後期照片比對**：前期、本期網站並排，各自捲到照片。
- **回到缺失主頁面**：看完照片後，把顯示中的網站開回本期／前期的檢測缺失主頁面。
- 網站被隱藏時，按照片按鈕會自動顯示對應的網站。
- 防呆：本期新增的缺失沒有前期，「前期照片」「前後期照片比對」不能按；只有前期（漏建、已維修）的缺失「本期照片」不能按。滑鼠停在按鈕上會說明原因。
- **修改本期**：多一欄「修改後」，可改 DERU（四個下拉）、劣化類型、損壞位置、維修工法、數量、單位、單價、備註：
  - 「導入前期」：帶入前期的劣化類型、位置、工法、數量、單位、單價與備註（DERU 維持本期），再點樣態按鈕只換備註中間的敘述；
  - 「樣態」按鈕與「Excel 規則」下拉只列與「修改後」劣化類型相同的規則（換類型時即時更新；該類型沒有規則才列全部）。按下會把備註中間的樣態換掉（保留位置與尺寸），帶入對應的工法、單位、單價，並依規則單位由備註尺寸重算數量與位置（例：前期 1 式、(10m*2m)，選混凝土沖蝕〔平方公尺〕→ 數量 20）；
  - 「Excel 規則」下拉：直接選一條規則，帶入劣化類型、工法、單位、單價並替換樣態；
  - 與網站不同的欄位標藍；按「儲存修改」存到審查檔，「還原網站值」清除修改。沒按儲存就「確認並下一筆」、上一筆／下一筆或在填寫清單換筆時，會**自動儲存**（紀錄寫「已自動儲存修改後欄位」）。
- 修改不會立即寫入網站，第 6 步填寫時才寫入。總表審查欄有 ✎ 表示已修改，可用篩選「已修改」列出。

查詢是程式唯一會在網站上填寫並按下的動作：只填「橋梁名稱」、只按同一表單的「開始查詢」，結果必須是查詢結果頁才繼續；查詢不會修改任何資料。

## 改配對

程式配錯對象，或同一筆缺失前後期記在不同構件（例：前期記在河道的掛淤，本期拆到橋墩基礎）時，在「逐筆審查」按「**改配對…**」：

- 選到有前期的一筆：列出本期缺失，可**勾多筆**（一筆前期拆成多筆本期，數量合計後判斷範圍加大／縮小）。
- 選到只有本期的一筆：列出前期缺失，選一筆；若那筆前期已配給其他本期，變成一對多。
- 候選清單排序：
  1. 同一構件列（未配對在前）
  2. 同構件其他列的未配對
  3. 其他構件的未配對（依樣態相似度；跨構件提示的那筆排最前）
  4. 已配給其他缺失（灰字，選了會把原配對拆開，留下的那筆改為需確認）
- 「拆開目前配對」：兩筆各自單獨，之後重新配對也不會再自動配在一起。
- 人工配對標示為「人工配對」、審查狀態「已改判」；跨構件者另標「位置變更（河道 → 橋墩基礎）」，總表構件欄顯示「河道 → 橋墩基礎」。
- 改配對存在審查檔，重新掃描後仍套用；篩選可選「人工配對」「位置變更」；比對 Excel 有「配對方式」欄。

**跨構件提示**：配對後剩下的疑似漏建與新增，若分屬 Excel「跨構件對應」頁列出的相關構件、樣態相同、位置代碼吻合（例：P2、P3掛淤 ↔ P2 掛淤），
理由欄會寫「可能對應…（位置變更）」，只提示、不自動配對。

## 填寫網站（② 送出資料）

**核對與填寫同步**：配對完成時同時產生填寫清單；總表多一欄「填寫」（可填寫、需確認、無需修改…，需確認整列標黃，與填寫分頁一致），篩選可選「填寫需確認」。逐筆審查會顯示這一筆的填寫狀態——需確認（黃色，附原因與「帶入程式建議」「確認維持現值」）、已確認維持現值（紫色）、可填寫（綠色，列出將填寫的變更），核對時就能一併處理；上方摘要同時顯示「填寫需確認 n」。在填寫分頁點選清單的任一筆，下方直接修改，不會跳回掃描＋核對。

切到「② 送出資料」會列出本期每一筆缺失（只有前期的漏建、已維修不在網站上，不列）：

| 狀態 | 意思 |
|---|---|
| 可填寫 | 有要填的變更，可以單筆或整筆送出 |
| 需確認 | 程式無法確定（例：Excel 有多個可用方案、備註量式看不懂、下拉選單沒有該選項）；在清單點選這一筆，下方直接修改（「帶入程式建議」或自行修改後「儲存修改」）就會變成可填寫；看過後不需修改就按「確認維持現值」 |
| 已確認 | 需確認的項目已人工確認維持網站現值（紫色，說明欄寫確認時間與程式原判）；之後若修改，仍以修改為準 |
| 無需修改 | 網站值已符合規則與修改 |
| 不填寫 | D＝1 或 E＝0（良好或無此項） |
| 已完成 | 已送出並回讀核對一致 |
| 待確認 | 上次送出結果不明（例如網路中斷），程式不會重送；下次填寫時先重新開啟核對 |
| 失敗 | 這次沒有送出（原因寫在說明欄），可修正後再試 |

**本期不完整時依前期補齊**（套用 Excel 規則之前，前後期為同一筆、劣化類型一致時）：

| 情況 | 處理 |
|---|---|
| 本期備註空白，前期尺寸換算＝本期數量（例：前期「A2 沖蝕 (10m*2m)」1 式，本期 20 平方公尺） | 導入前期位置與敘述、前期尺寸，數量與單位用本期 |
| 本期備註只有尺寸，換算＝前期數量（例：本期「(10m*2m)」，前期 20 平方公尺） | 導入前期位置與敘述，尺寸用本期 |
| 單位也一致，本期只留新尺寸（例：本期「5*7」，前期「A1 混凝土剝落 (4m*5m)」） | 視為同一缺失：導入前期位置與敘述，範圍改新尺寸並補括號與單位 →「A1 混凝土剝落。(5m*7m)」，數量 35 |

本期有寫位置時以本期為準（例：「A3 5*7」）；劣化類型或單位不同、尺寸換算不符、本期已有完整敘述時不套用。說明欄會寫明「已導入前期位置與敘述」。

**預定值**＝網站現值 → 套用程式建議（v1.00 的 Excel 規則判斷，前期資料以配對結果為準；跨構件配對不帶前期）→ 再套用你在逐筆審查的修改（修改優先）。只填與網站不同的欄位；D/E/R/U 只在你修改時才填。

- **單筆修正**：在表格選一筆後按下，只填這一筆。
- **整筆自動**：填寫全部「可填寫」。送出前會列出筆數與變更內容請你確認。
- 每一筆的步驟與保護：
  1. 開啟第二級編輯頁，**建議維修工法 ID 必須與清單一致**，不一致就停止；
  2. 網站現值必須與掃描時相同（有人改過就停止，請重新掃描，不覆寫）；
  3. 填入後先讀回確認，再記錄「待確認」並按「送出更新」；
  4. 送出後**重新開啟回讀**，與預定值一致才記為「已完成」；不一致保留「待確認」，**不會自動重送**；
  5. 遇到結果不明（待確認）整批立即停止，等你確認。
- 填寫用的是背景頁面：只能開第二級編輯頁，只在按送出的那一刻允許一次送往 update_damage 的表單送出；刪除、新增等其他網址一律擋下。
- 填寫進度存在 `temp/review/日期-橋名-填寫.json`，中斷後可接續；已完成的不會重送。
- 填寫完成後，左側本期網站會重新載入缺失主頁面，並**自動重新掃描本期**（前期沿用上次掃描），清單與審查依網站最新資料更新；已填進網站的修改不再算「已修改」。也可隨時按「重新掃描本期」。

### Excel 沒有對應規則時自動新增

清單計算時若遇到「Excel 無對應值」，程式依規則格式自動新增到規則表，再重新計算：

| 情況 | 新增方式 |
|---|---|
| 劣化類型判讀差異（同構件有相同樣態，但劣化類型不同） | 複製該規則，只改劣化類型；填寫時帶入該規則的工法、單位、單價 |
| 新的劣化樣態（同構件沒有這個樣態） | 樣態取自本期備註；工法、單位、單價取自本期網站值（網站值不完整時複製最相近的規則） |

- 新增的列：處理方式「自動」、任一關鍵字＝該樣態、依單位給備註範本、劣化ID 接續該工作表最後一號；「說明」寫明來源橋梁與 ID，**黃底待確認**。
- 寫入前先備份到 `backup/`；使用中的規則表是 `data/劣化說明與維修單價1116.xlsx`；舊的 1111v2 中程式自動新增的規則，啟動時會搬入 1116，舊檔移到 `backup/`。
- 規則表在 Excel 中開啟時無法寫入，紀錄會提示，關閉後按「重新整理」即可。

## 審查狀態與判定

| 審查狀態 | 意思 |
|---|---|
| 已確認 | 程式高信心的配對自動視為已確認；或你確認了程式的判定 |
| 待審查 | 程式判為需確認，等你確認或改判 |
| 已改判 | 你選了與程式不同的判定 |

| 配對類型 | 可選判定 |
|---|---|
| 前期與本期都有 | 沿用、範圍加大、範圍縮小、單位數量變更、**前期選擇或填寫錯誤** |
| 只有本期 | 新增 |
| 只有前期 | 已維修、**已消失**（例：河水沖刷，掛淤已無）、**確實漏建**、疑似漏建、**與其他缺失重複合併**、**前期選擇或填寫錯誤** |

只有前期的缺失可選「**與其他缺失重複合併**」：前期分兩筆記、本期合成一筆的情況（例：保護層不足與鋼筋外露視為同一缺失），本期不另建，不算漏建。同一構件列中前期多出的那筆，若與本期某一筆屬於同一組（目前：保護層不足／鋼筋外露），程式會自動判為此類（需確認），理由寫明合併到哪一筆。

前期與本期都有時也可選「**前期選擇或填寫錯誤**」：前期的劣化類型、工法、單價或備註有誤，本期不應沿用。選了之後，填寫清單與「帶入程式建議」只依本期與 Excel 規則計算，不參考前期資料；總表可篩選這一類。
