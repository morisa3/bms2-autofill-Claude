# 主程式：掃描並配對、審查（第 5 步）

雙擊 **`填報助手.bat`** 開啟。本步驟**全程唯讀**，不會修改網站資料。

## 畫面

| 區塊 | 內容 |
|---|---|
| 左側 | 內嵌網站（沿用登入狀態）。按「隱藏網站」可收起，小螢幕時把空間留給審查 |
| 上方 | 「定期檢測查詢」「基本資料搜尋」捷徑；「掃描並配對」；「開啟掃描檔…」 |
| 右側「總表」 | 每組配對一列：審查狀態、構件、位置、判定、信心、前期與本期備註、理由。可篩選；雙擊開啟逐筆審查 |
| 右側「逐筆審查」 | 前期與本期欄位並排，不同的欄位標色；選判定、寫說明後按「確認並下一筆」 |
| 右側「紀錄」 | 掃描過程與核對異常 |

## 步驟

1. 開啟後先在左側網站**登入**（之後會記住登入狀態）。
2. 在上方「橋名」輸入橋名，按「**開始**」（或按 Enter）。程式自動：
   - 用網站的「定期檢測 → 進階查詢」查詢橋名；
   - 查到**多座相似的橋**（例如龍門大橋、龍門大橋(2)），或橋名不完全相同時，跳出清單請你選擇（顯示橋梁系統ID、管理機關、所在地、最新檢測日期）；只有一座且同名時直接處理；
   - 由歷史定期檢測紀錄取最新一期為**本期**、前一期為**前期**，左側網站同步開到本期缺失主頁面；
   - 唯讀掃描本期、前期、基本資料，完成前後期配對。
3. 總表上方顯示「待審查 n」。篩選「待審查」或到「逐筆審查」（預設只在待審查之間移動）逐筆處理。
4. 審查結果自動存到 `temp/review/`；下次按「開啟掃描檔…」選同一期的 `*-檢測.json`，可接續審查，不必重新掃描。

其他按鈕：「掃描目前頁面」掃描左側網站目前開著的缺失主頁面（例如要處理的不是最新一期時）；「定期檢測查詢」「基本資料搜尋」只是把左側網站帶到該頁。

查詢是程式唯一會在網站上填寫並按下的動作：只填「橋梁名稱」、只按同一表單的「開始查詢」，結果必須是查詢結果頁才繼續；查詢不會修改任何資料。

## 審查狀態與判定

| 審查狀態 | 意思 |
|---|---|
| 已確認 | 程式高信心的配對自動視為已確認；或你確認了程式的判定 |
| 待審查 | 程式判為需確認，等你確認或改判 |
| 已改判 | 你選了與程式不同的判定 |

| 配對類型 | 可選判定 |
|---|---|
| 前期與本期都有 | 沿用、範圍加大、範圍縮小、單位數量變更 |
| 只有本期 | 新增 |
| 只有前期 | 已維修、**已消失**（例：河水沖刷，掛淤已無）、**確實漏建**、疑似漏建 |

審查結果是第 6 步（依 ID 填寫網站）與第 7 步（檢測員意見）的依據。
