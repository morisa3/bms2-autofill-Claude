# 公路橋梁填報助手 4.x 操作說明

適用版本：4.0.000.0 起（版本號在視窗標題；各版內容見「版本紀錄」）。

> **4.0 重大新功能速覽**：
> - **橋梁總表 38 欄定稿版**＋支援 25 墩以上大型橋梁的「欄杆至河床高度(m)」自動計算；
> - **檢測員意見精簡版**：③ 分頁可切換「詳細版／精簡版」，精簡版自動跨構件合併 `U=2、E<3` 缺失，並將 `E≧3`（排除伸縮縫漏水）獨立出來由人工判斷是否需維修；
> - **Google 試算表多人即時同步**：⑥ 分頁可切換本機 Excel 或 Google 試算表，多人同時開表不鎖檔、保留人工修改，並可一鍵匯出不跑版 38 欄本機 `.xlsx`（設定詳見 `Google試算表同步設定.md`）；
> - **v3 三層整併規則表**（`data\劣化說明與維修單價v3.xlsx`）：同列並列多單位單價＋跨構件「通用規則」基底表＋8 張設定工作表全面生效；
> - **總表驅動排程＋監看時段輪詢**：排程可直接從總表依鄉鎮勾選橋梁並帶入二代系統ID、自動防重複橋名誤判（含改建新舊橋保護），並支援監看時段輪詢＋上傳穩定緩衝與「▶ 立即掃描剩餘排程」。

## 一、安裝與開啟

1. 把 `公路橋梁填報助手.exe` 放到一個**專用資料夾**（例如 `D:\填報助手\`），不需要安裝。
   建議不要放在桌面、OneDrive 或下載資料夾（同步或防毒軟體可能鎖住檔案）。
2. 雙擊開啟。第一次開啟約需 10～30 秒（程式要先解壓縮）。
   - 若出現「Windows 已保護您的電腦」：點「其他資訊」→「仍要執行」。
3. 第一次開啟後，資料夾內會自動建立：

| 資料夾 | 內容 |
|---|---|
| `data\` | 劣化說明與維修單價 Excel 規則表（可自行修改，**修改時先關閉程式**） |
| `temp\` | 本期操作：掃描檔、審查與修改紀錄（歷史紀錄從這裡讀取） |
| `scan\` | 總表用的前期與基本資料：`scan\縣市政府\pre-brigdedata\工作表`（前期檢測資料）、`scan\縣市政府\pre-brigdeFEdata\工作表`（橋梁基本資料）；已掃描過的前期會沿用 |
| `判讀結果\` | 輸出的前後期比對 Excel |
| `browser-profile\` | 內嵌網站的登入狀態 |
| `log\` | 錯誤紀錄（`錯誤紀錄.txt`，程式出問題時請提供這個檔案） |
| `backup\` | 規則表自動新增規則前的備份 |

升級新版時，只要用新的 exe 取代舊的，資料夾都保留。

（原始碼版：雙擊 `填報助手.vbs` 開啟，不會出現黑色 CMD 視窗；第一次會先開一次安裝視窗。）

## 二、登入

- 在左側網站登入（帳號、密碼、勾選「我不是機器人」）。登入狀態會記住。
- **記住帳號密碼**：右上「其他功能」→「記住帳號密碼…」。**可存多組**，每組加一個標籤（例：雲林縣、嘉義縣），存在 Windows 認證管理員。
  登入頁會自動填入「預設」那組，只要勾選驗證、按「確定登入」；要換帳號：「其他功能」→「登入頁填入帳號」選標籤（同時設為預設）。

## 三、每日流程

1. **開始**：上方「橋名」輸入橋名按「開始」；**同名的橋可改輸入二代系統ID**（純數字），直接用 ID 查詢。
   - **第一次檢測**（歷史紀錄沒有更早的檢測）：不會跳錯，本期缺失全部視為本期新增，照樣依 Excel 規則修正與送出。
   - 一次多座：`德安橋、萬年橋、產業三號橋`（以「、」或逗號分隔），依序自動掃描，之後從「歷史紀錄」逐座開啟。
   - 排程：「其他功能」→「排程掃描…」，輸入橋名（或二代系統ID）與時間（例 16:00）按「加入排程」；**可以分次加入多座**（會累加，不會取代前一筆，清單中可移除）。
     關閉排程視窗後程式**先掃描各橋的前期建檔**；時間到只掃描本期（沒有本期紀錄的橋只存前期，下次再掃時只掃本期）。等待期間程式會保持登入。程式要開著並已登入。
   - 前期資料不會再改動：同一座橋的前期掃描過一次後就一直沿用，不再重掃（重新掃描也只掃本期）。
   - 網站還沒有本年度檢測紀錄時，程式會先把前期掃描建檔，等本年度紀錄建好後再按「開始」就只掃描本期。
   - 「歷史紀錄」的橋名後面會顯示所屬縣市（例：湖子內橋（雲林縣）），開啟前請確認和左側網站登入的帳號是同一縣市。
     掃描、上傳照片、寫入意見期間不能開啟其他紀錄（狀態列會提示）；② 送出資料期間可以。
2. **① 核對與修改**：數字卡片「待處理」逐筆處理。
   - 本期欄直接顯示**將填寫的值**（藍底＝會修改網站），按「確認並下一筆」即確認。
   - 要改：按「修改本期」直接在本期欄修改；「導入前期」「樣態」「Excel 規則（對應規則清單）」可快速帶入。
   - 「**沿用前期資料**」：劣化類型、位置、工法、數量、單位、單價、備註完全沿用前期（DERU 維持本期），只修正括號、乘號與空格寫法（例：「A1 混凝土裂縫 （1m*0.3mm)*2」→「A1 混凝土裂縫(1m*0.3mm)*2」），不套用 Excel 規則。
   - 「回到缺失主頁面」：看照片後在網頁上操作過（刪照片等）也能用；網站關閉第二級頁時會自動回到缺失主頁面。精簡網頁只在主頁面載入時不下載檢測人員照片，之後自己開的第二級損壞照片照常顯示。
     下拉選單要先點一下才能用滾輪選，沒點過時滾輪只會捲動畫面，不會改到值。
   - 「可送出」中標「未確認」的是程式高信心判定：可逐筆按「確認並下一筆」（篩選「可送出」時會跳到下一筆未確認的），或看過沒問題按「確認全部」。
   - 「本期照片／前期照片／前後期照片比對」看照片；「工作區放右側」適合 1080p 螢幕。
   - **雙螢幕**：「其他功能」→「網站放到另一個螢幕（雙螢幕）」：網站移到另一個螢幕（最大化），主視窗只留工作區；關掉網站視窗或取消勾選即放回。設定會記住，下次有兩個螢幕時自動沿用。
   - **本期照片自動開啟**：「本期照片」按住 2 秒，按鈕變成「**自動開啟**」（維持按下的樣式）：之後每換一筆（上一筆／下一筆或點清單）就自動開啟該筆的本期編輯頁並捲到損壞照片，方便逐筆刪照片；本期沒有這筆的會略過。再按住 2 秒改回「本期照片」。設定會記住，下次開程式沿用。
3. **② 送出資料**：整批送出、依構件送出，或多選送出。每筆送出後自動回讀核對，結果不明不會重送。
   - 送出期間可以從「歷史紀錄」開啟另一座已掃描的橋繼續核對，送出在背景繼續（完成時紀錄區會提示）。
   - 送出後不會自動重新掃描；需要確認網站最新資料時再按「重新掃描本期」。
   - **網路不穩**：開頁面、回讀這類只讀取的步驟失敗會自動等幾秒重試（最多 2 次），**送出絕不重送**；連續 3 筆連線失敗會整批暫停並提示。
     網路恢復後：有「待確認」的先按 **「核對待確認」**（只讀網站，不送出：已寫入的改為已完成，沒寫入的改回可送出），再按送出接續。
     核對後仍待確認（網站內容與預定值都不同）的，會列出哪個欄位網站是什麼、預定是什麼；到網站人工確認內容正確後，可選擇標為「已完成」（以網站現值為準，不會再送出），橋名顏色才會變成完成。損壞位置、備註中的半形分號「;」網站儲存時會改寫，核對時已忽略分隔符號差異。
4. **③ 送出檢測員意見**：依 ① 本期欄「將填寫的值」產生意見（核對完就能產生，不必先送出、重新掃描）。勾選條目增減，右側可直接修改（刪掉一條會自動取消勾選並重新編號），填完【】後「寫入網站」。
5. **④ 上傳基本照片**：**不需掃描**——按「選擇橋梁…」輸入橋名（或沿用已掃描的橋）。依版本產生六格，從檔案總管把照片拖進格子，勾選後「上傳選取的照片」。
   - 跨水橋：橋頭近照、橋尾遠照、往外上游、往外下游、上游側照、下游側照
   - 陸橋：橋頭近端、橋尾遠端、右側側照、左側側照、往外右側、往外左側
   - 雲林縣（管理機關為雲林縣政府時自動使用）：橋頭近端、橋尾遠端、橋左側照、橋右側照、往外上游、往外下游
   - 雲林縣陸橋（雲林縣政府、不是跨水橋）：橋頭近端、橋尾遠端、橋左側照、橋右側照、往外右側、往外左側
   - **各縣市政府自訂**：「其他功能」→「照片標題（各縣市政府）…」選縣市政府，跨水橋、陸橋各填六個標題（灰字為預設，六個都填才採用，空白＝用預設），存在 `data\photo_titles.json`；照片頁依管理機關自動套用，已上傳判斷與「修正照片標題」也認得自訂標題。
   - 版本可在「橋梁類型」手動切換。
   - 選擇橋梁或切到本頁時會讀網站照片簿，顯示**最新照片的拍照日期**與各張最新日期；本年度已有同標題照片的格子標「網站已有」，不會再勾選上傳。
   - 本年度照片簿已有**任一版本（跨水橋／陸橋／雲林縣）完整六張**，或六張標題**混用各版本**（橋頭、橋尾都有）：六格都標「網站已有」，總表「六張基本照片拍攝」也判為「是」。
   - **修正照片標題**：本年度照片標題不是目前版本時（例：雲林縣的橋用跨水橋的「上游側照」上傳），「橋梁」那一列會出現「**修正照片標題（N 張）…**」。
     按下後列出「拍照日期｜目前標題｜改成」：橋頭近照↔近端、橋尾遠照↔遠端自動對應，其餘依序補到缺少的標題，**上下游與左右側請依現場方向確認**（可改選或選「不修改」，新標題不能重複）。
     按「確定修改」後逐張開該照片的修改頁，**只改標題**（拍照日期、說明、照片不動，不刪除），送出後重新讀照片簿核對；結果不明標「待確認」不重送。
6. **⑤ 比對資料輸出**：輸出前後期比對 Excel 到 `判讀結果\`，含「淨高」工作表（本期／前期意見、程式產生、基本資料）。
   - 「前後期比對」：前期（網站原始資料）對照**本期修改完成的資料**（Excel 規則＋人工修改後將送出的值）；編號同核對頁簡化（A1、P1、S3…）。
   - 欄位：構件、編號、前期 DERU／劣化類型／備註／數量／單位／有無維修紀錄、本期 DERU／劣化類型／備註／數量／單位、**判定**（既有劣化沿用、U值上升、U值下降、本期新增、漏建劣化）、**變化**（不變、數量變更、改類型、已維修、本期無發現該劣化）；本期新增黃底、漏建橘底、U值上升紅底、U值下降淺藍、已維修／無發現綠底。
   - 程式需要的 ID、判定等欄位放在最後並縮到看不到（同步總表、同事的比對資料會讀這些欄）。
   - **下橋路徑與輔助設備**（3.0）：先選等級，畫面只顯示該等級的選項：
     - D、C 級：勾下橋位置（A1上游側、A1下游側、A2上游側、A2下游側，可多選）、選方式（D：徒步／既有檢修梯；C：架設一／二／三截梯），需要時勾「水深需要」長筒雨鞋／青蛙裝。
     - B 級：勾橋檢車／高空作業車／工作船；A 級：勾空拍機／水下攝影機。會同時填好「輔助設備(A/B)」。
     - 「備註」可手打；下方兩格是實際輸出的文字，也可直接修改（以修改後為準）。
     - 例：C → 「C 換行 A1下游側架設二截梯下橋 換行 水深需要長筒雨鞋」；B → 「B 換行 需用橋檢車檢測」，輔助設備「B 換行 橋檢車」。
     - 每座橋自動存檔；輸出的比對 Excel 多一張「下橋路徑」工作表，⑥ 同步時寫入總表這兩格（沒設定則不動總表原有內容）。
     - 開啟橋梁時沒有存檔，會從橋梁總表讀回（例：去年填的）；也可按「從橋梁總表讀取」。

## 三之一、⑥ 同步到橋梁總表（縣市 Excel 總表）

切到「⑥ 同步到橋梁總表」，依頁面上的步驟操作。按鈕會顯示進度（例：尚缺 ID 3 座、已建檔 30／68）；
沒有總表時建檔按鈕不能按，已完成的步驟再按會先確認是否重做。**寫入總表時總表檔要先關閉**（Excel 開著無法寫入），每次寫入前會備份到 `backup\`。

程式產生或同步過的總表，最前面都有「**說明**」工作表：顏色意義、下橋路徑與輔助設備判定、各欄由誰填寫。

### 步驟 1　準備總表（第一次使用、或換年度時）

| 你手上有 | 按 | 說明 |
|---|---|---|
| 什麼都沒有 | 建立空白總表範本… | 輸入工作表名稱（可多個，例：西螺、莿桐）並存檔；用 Excel 依序填「序號」「橋梁名稱」，「二代系統ID」知道就填、不知道留空，存檔後關閉。 |
| 前期（去年）的總表，或 Google 試算表下載的 xlsx | 導入前期總表… | 選前期總表 → 選擇是否有本期檢測橋梁清單 → 另存新檔。程式把前期總表轉成程式格式；有本期清單時，清單有、前期沒有的橋加在該工作表最後、序號註記「（新增）」，前期有、清單沒有的註記「（解除管養）」。 |
| 已是程式格式的總表 | 選擇總表檔… | 直接選擇即可。 |

本期檢測橋梁清單＝「建立空白總表範本」填好橋名的檔案。

### 步驟 2　建檔（本期檢測前先建好前期資料）

0. 總表有橋缺二代系統ID 時，步驟 2 會出現「**缺 ID 的橋（N 座）**」按鈕，按下列出是哪幾座（工作表、序號、橋名），可直接開始比對。
1. **只有橋梁清單**：先按「**比對橋梁ID與基本資料**」（只讀基本資料，很快）。
   - 程式依橋名找出二代系統ID 寫回總表，並核對系統資料（不同的標橘底加備註）。
   - 同名多座或查無的，最後跳出**手動配對**視窗：從下拉選正確的橋，或「重新查詢…」換關鍵字，也可略過。
2. 按「**建立前期劣化資料**」：掃描前期，寫入前期觀測劣化、過去維修紀錄等，並核對基本資料。
   - 已導入前期總表或 ID 都已填好時，可以直接從這一步開始。
   - 「判讀結果」資料夾有該橋本年度的比對 Excel（同事用 ⑤ 輸出的也可以）時，會一併寫入本期資料。
3. **進度與續做**：完成的橋**序號標綠色**、未完成標**黃色**，每 10 座存檔一次。
   - 中斷（停止、關閉程式、網路斷線）後，再按同一個按鈕選「**接續**」，從未完成的繼續；選「**全部重新**」則全部重做。
   - 黃色是因為找不到 ID 的：在總表「二代系統ID」欄手動填入、存檔關閉後，再按「建立前期劣化資料」選「接續」。
4. **新建橋梁**：沒有前期檢測紀錄的橋，前期觀測劣化寫「本橋為新建橋梁，未有前期資料」，序號標綠色。
5. **已拆除的橋**：系統橋名標示「已拆除」的橋，建檔完成後會列出提醒（可能是 ID 填錯或已改建）。
   在 Excel 修正（更正二代系統ID、橋名，或在序號註記「解除管養」）、存檔關閉後按「**重新掃描異動**」：只重做 ID 或橋名有改過的橋。
6. **重新建立前期劣化資料…**：某座橋 ID 填錯、前期資料不對時使用。
   - 先在總表把 ID 改成正確的、存檔關閉，按這個按鈕輸入新的二代系統ID。
   - 程式在總表找到該列後，清掉程式整理的資料（ID、橋名、下橋路徑、輔助設備與人工欄位保留），舊的前期掃描檔移到 `backup\`，重新讀取基本資料與前期資料並建檔。
7. **版型**：「建立空白總表範本」與導入、轉換的總表都用西螺工作表的表頭與欄寬；欄位不隱藏、不縮小，長文字自動換行。

### 步驟 3　本期資料寫入總表

1. 本期檢測照平常流程：開始 → ① 核對與修改 → ② 送出 → ③ 檢測員意見寫入網站。
2. 按「**同步目前開啟的橋**」（勾選「③ 寫入檢測員意見後自動同步」時，③ 寫入後會自動同步）。①②③ 都完成的橋，橋名變綠色（③ 在網站手動寫入意見也算）；還沒變綠色時，同步結果會列出還沒完成的步驟。
3. 要一次同步多座已掃描的橋：「**批次同步已掃描的橋…**」，勾選歷史紀錄中的橋。
4. 排程掃描視窗勾選「掃描後同步到橋梁總表」，時間到掃描後自動寫入。

### 人工修正

程式寫入的儲存格會加上「**填報助手產生**」備註（含識別碼）。你在 Excel 修正這些儲存格後，之後再同步時**不會被覆寫**（同步結果會列出「已人工修正，保留不覆寫」）。
要讓程式重新產生，刪掉那一格的內容或備註即可。導入前期總表（換年度）時，上一期的程式備註會清除，重新產生。

## 四、現場檢測時，劣化怎麼填，程式可以自動帶入前期

程式會用「**同一構件、同一劣化類型**」的前期資料補齊本期，並依 Excel 規則修正工法、單位、單價與備註寫法。
所以現場（App 或網站）填寫時，**劣化類型請選和前期相同**，其餘照下表填，越少越好：

| 情況 | 本期只要填 | 程式自動完成 |
|---|---|---|
| 和前期相同、範圍沒變 | DERU、劣化類型；數量可填可不填；**備註留空** | 導入前期位置、敘述、尺寸、數量、單位，再套 Excel 規則 |
| 範圍改變（面積、長度、裂縫） | DERU、劣化類型；**備註只寫新範圍**，例 `5*7`、`0.5mm*2m*2` | 位置與敘述沿用前期，範圍改成新尺寸並補單位，數量自動計算。例：前期 `A1-L,R 裂縫。(2m)*2`、本期只填 `0.5mm*2m*2` → `A1-L,R 混凝土裂縫。(0.5mm*2m)*2` |
| 計數單位（處、個、支…）數量改變 | DERU、劣化類型、**數量** | 備註改成 `(數量處)`，位置與敘述沿用前期 |
| 前期為「1式」，本期改成實際數量 | DERU、劣化類型、數量（與前期尺寸換算相符） | 自動改成正確單位（例：(5m*2m*1m) → 10 立方公尺） |
| 位置相同、敘述不同 | 備註只寫敘述，例 `漏水。` | 補上前期位置；長度單位依數量補範圍，例 `P1 漏水。(5m)` |
| 新增的缺失（前期沒有） | 備註完整寫：`位置 樣態。(尺寸)`，例 `A1-R 混凝土剝落。(1m*2m)` | 依 Excel 規則帶入工法、單位、單價 |
| 尺寸沒寫單位 | 例 `A1 AC龜裂 5*7`、`A1 路面混凝土層破洞 1*2*3` | 補單位與括號：`(5m*7m)`（平方公尺）、`(1m*2m*3m)`（立方公尺） |
| 只寫樣態（位置不變） | 例 `AC龜裂` | 補上位置（前期有位置就沿用，沒有用構件位置，例 A1）與尺寸範本：`A1 AC龜裂。(m*m)`，請在 ① 把 m 改成實際尺寸 |
| 引道路堤 AC 缺失沒寫尺寸 | 例 `AC龜裂` | 依基本資料最小淨寬 × 5m 估算，例淨寬 7.5m → `A1 AC龜裂。(5m*7.5m)`、37.5 平方公尺 |

小提醒：

- 樣態寫法以 Excel 規則表為準；常見的不同寫法會自動轉換（Excel「樣態同義詞」），例：老化 → AC剝離、火害 → 表面燻黑、鋼筋未剪 → 鋼筋未切、破損鋼筋外露鏽蝕 → 混凝土破損鋼筋外露。
- 「銹蝕／鏽蝕」代表鋼筋外露：`破損銹蝕` → 混凝土破損鋼筋外露、`蜂窩鏽蝕` → 混凝土蜂窩鋼筋外露、`混凝土剝落，鋼筋外露` → 混凝土剝落鋼筋外露（所有構件）。
- 植物生長：U＝1 自動寫草本植物生長、U＝2 寫木本植物生長。
- 位置寫法自動修正：主梁 `S2G5` → `2G5`、橫隔梁 `1D-2-1` → `1D2-1`、橋護欄與排水設施 `整體-ALL` → `整體-L,R`。
- 劣化類型和前期不同時，視為不同缺失，不會帶入前期（需在 ① 手動處理）。
- 同一構件有多筆同類型缺失時，程式依位置與樣態配對；配錯時在 ① 按「改配對…」。
- Excel 沒有的樣態：前後期同樣態時沿用前期工法、單位、單價；全新的樣態會**先跳出提示**列出要新增的規則，選「是」才新增到 Excel（說明欄黃底，請確認），選「否」則不新增、該筆留在需確認（本次執行不再詢問）。批次或排程掃描時不新增，開啟該橋時再詢問。
- 備註的尺寸沒寫單位（例：橋墩基礎「P3 基礎裸露 4*3*1.5」）或只寫本期深度（「P3 基礎裸露 1.5」）：不會被當成新樣態；前期為「長*寬*深」時，依前期格式補成「(4m*3m*1.5m)」（只寫深度時長寬沿用前期）。

## 五、注意事項

- 程式只在 ②③④ 按下送出並確認後才修改網站；不會刪除任何缺失或照片。
- 送出後會重新讀取核對；結果不明的標「待確認」，**不會自動重送**，請到網站確認。
- 修改 `data\` 的 Excel 規則表：存檔並關閉 Excel 後，到「其他功能 → 規則表（劣化說明與維修單價）…」按「重新讀取」即生效（不用重開程式）。這個視窗也會顯示目前讀到哪個規則表、幾條規則；沒讀到時會說明原因，可「選擇規則表…」改用其他檔案。
- 程式出錯或無法開啟：請提供 `log\錯誤紀錄.txt`。
