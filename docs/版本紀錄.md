# 版本紀錄

版本號格式：**2.x.yyy.0**（自 2.0 定稿起計）

- **x**：新增功能時加 1，yyy 歸零。
- **yyy**：錯誤修正時加 1。
- 程式視窗標題與打包檔名都顯示版本號；版本號寫在 `bridgefill/version.py`。
