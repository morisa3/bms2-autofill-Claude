# 版本紀錄

版本號格式：**4.x.yyy.0**（2.x 自 2.0 定稿起計；3.0 起為 3.x；4.0 起為 4.x）

- **x**：新增功能時加 1，yyy 歸零。
- **yyy**：錯誤修正時加 1。
- 程式視窗標題與打包檔名都顯示版本號；版本號寫在 `bridgefill/version.py`。
