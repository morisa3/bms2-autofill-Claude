# 版本紀錄

版本號格式：**2.x.yyy.0**（自 2.0 定稿起計）

- **x**：新增功能時加 1，yyy 歸零。
- **yyy**：錯誤修正時加 1。
- 程式視窗標題與打包檔名都顯示版本號；版本號寫在 `bridgefill/version.py`。

| 版本 | 類型 | 內容 |
|---|---|---|
| 2.6.000.0 | 新功能 | 規則表改用 1120（劣化ID 重複改號、記入修訂紀錄）；鋼筋外露的「剝落／破損／蜂窩／碎裂＋銹蝕／鏽蝕」關鍵字補到所有構件；排程加入後先掃描前期建檔，時間到只掃本期（已掃過的前期一律沿用不重掃）；記住帳號密碼可存多組並加標籤（預設帳號自動填入，「登入頁填入帳號」切換）；歷史紀錄顯示橋梁所屬縣市；④ 顯示照片簿最新照片日期，本年度已上傳的標「網站已有」；備註補單位與括號（5*7 → (5m*7m)、1*2*3 → (1m*2m*3m)）、只寫樣態時補上位置與尺寸範本（AC龜裂 → A1 AC龜裂。(m*m)）、引道路堤 AC 缺尺寸時依最小淨寬×5m 估算。修正：數量 400 顯示成 4E+2（科學記號）；「混凝土剝落，鋼筋外露」被判成混凝土剝落（漏了鋼筋外露）；結果相同的兩條規則（例：1-03 與 1-12）被當成多個方案 |
| 2.5.000.0 | 新功能 | ④ 上傳基本照片不需掃描：「選擇橋梁…」只查詢橋名並讀基本資料即可上傳（之後掃描同一座橋會接續照片安排）；上傳加速：背景頁面不下載圖片（照片簿縮圖是原尺寸照片）、同一批連續上傳沿用上一張讀到的照片簿 |
| 2.4.000.0 | 新功能 | 送出資料期間可從「歷史紀錄」開啟其他已掃描的橋繼續核對（送出在背景用原橋進度檔繼續）；送出後不再自動重新掃描（需要時按「重新掃描本期」）；比對資料輸出新增「淨高」工作表（意見本期／前期、程式產生、基本資料）與標題下摘要；修正：樣態按鈕在單位空白（空白沿用）或「式」時選錯單位的規則；修正：篩選「可送出」時「確認並下一筆」跳到下一筆未確認的可送出 |
| 2.3.000.0 | 新功能 | 介面外觀改為方案 A「Windows 11 辦公風」：微軟正黑體、淺灰底白色內容區、分頁藍色底線、圓角按鈕、主要按鈕藍色實心（開始、確認並下一筆、確認全部可送出、整批送出、寫入網站、上傳選取的照片、輸出比對 Excel）、表格斑馬紋；列高依字型調整；工作區較窄時工具列自動改用短名稱（照片比對、回主頁面、放右側、重掃本期、重整、篩選），空間足夠時顯示完整名稱 |
| 2.2.000.0 | 新功能 | 檢測員意見改用工作區本期欄「將填寫的值」產生（不必先送出、重新掃描）；新增「填報助手.vbs」，原始碼版執行時不開 CMD 視窗 |
| 2.1.001.0 | 修正 | 本期只填 DERU、劣化類型（備註空白）時，與同構件同劣化類型的前期配對（唯一者高信心、多筆依 DERU／數量）；本期單位空白不再判為單位數量變更。2026-11-19 五座橋：填寫需確認 34 → 10 |
