# Google 試算表直寫同步設定（不鎖檔、版型不跑掉）

使用本功能後，團隊多人可同時在瀏覽器開著《115年北雲林自檢橋梁總表》填寫下橋路徑與人工欄位；
填報助手則透過 Google Apps Script 即時寫入單一儲存格，完全不會鎖檔，也能隨時一鍵匯出完美排版的正式 `.xlsx`。

---

## 一、在 Google 試算表部署 Apps Script（全團隊只需設定一次）

1. 在瀏覽器開啟你的 Google 試算表（例如《115年北雲林自檢橋梁總表(請每日更新)》）。
2. 點選上方選單：**擴充功能** → **Apps Script**。
3. 清空編輯器原本的程式碼，將專案中 `tools/google_sheets/Code.gs` 的全部內容複製貼上。
4. 修改最上方第 13 行自訂一組團隊密碼（金鑰）：
   ```javascript
   const SECRET_TOKEN = '例如：yunlin-bridge-115';
   ```
5. 按上方存檔（Ctrl+S），點右上角 **部署** → **新增部署作業**。
6. 點選齒輪圖示選 **網頁應用程式**：
   - **執行身分**：選 **我**
   - **誰可以存取**：選 **所有人**（放心，沒有你的 `SECRET_TOKEN` 金鑰無法讀寫任何資料）
7. 按 **部署**，首次部署會要求授權存取此試算表，依提示允許即可。
8. 複製畫面上顯示的 **網頁應用程式網址**（開頭為 `https://script.google.com/macros/s/.../exec`）。

---

## 二、在填報助手設定連線

1. 開啟填報助手，切到 **「⑥ 同步到橋梁總表」**。
2. 總表來源選 **「Google 試算表（多人共用不鎖檔）」**。
3. 按 **「設定雲端連線…」**，貼上剛才的 **網頁應用程式網址** 與 **金鑰**，按 **測試連線** 顯示試算表名稱即完成。
4. **多個試算表**（例：北雲林、南雲林各一份總表）：每份試算表都照上面步驟部署 Apps Script，在設定視窗按「新增」，貼上網址與金鑰、按「測試連線」（連線名稱自動帶入試算表名稱，可修改）後「儲存」。存了兩組以上時，⑥ 頁面「設定雲端連線…」左邊會出現下拉選單，切換要寫入的試算表；同步、匯出正式排版 Excel（預設檔名用連線名稱）、排程「從橋梁總表勾選…」都用目前選的那一份。不要的連線在設定視窗按「刪除」（只刪程式裡的設定，不動試算表）。
4. 之後照平常操作：
   - 按 **「同步目前開啟的橋」**（或勾選 ③ 寫入後自動同步）：只精準寫入該座橋的程式欄位，不影響同事編輯。
   - 需要交件或留存正式排版 Excel 時，按 **「從雲端匯出正式排版 Excel…」**：自動依 38 欄標準版型（標楷體 10、正確欄寬列高、凍結 E2、全跨數欄杆至河床高度）在本機產出 `.xlsx`，絕不跑版。
