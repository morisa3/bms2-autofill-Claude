# 內嵌登入測試（第 2 步）

新版要把 bms2 網站直接嵌在程式視窗裡，不再另開 Chrome。這個小程式只測試一件事：**在內嵌視窗裡能不能正常登入，並維持登入狀態**。

程式不讀取、不填寫帳號密碼，也不操作驗證碼，一律由你在頁面中自己輸入、自己勾選。測試紀錄不含帳密與 Cookie。

## 執行方式

1. 從 GitHub 下載分支 `claude/eloquent-euler-7ghqms`（Code → Download ZIP），解壓縮。
2. 電腦需要 Python 3.12（和 v1.00 相同）。
3. 雙擊 **`登入測試.bat`**。第一次執行會建立 Python 環境並安裝 PySide6，約需 1～3 分鐘。

## 測試步驟

| 步驟 | 動作 | 預期結果 |
|---|---|---|
| 1 | 開啟後等登入頁出現 | 上方黃色提示列：「請在下方頁面自行輸入帳號密碼並完成驗證」 |
| 2 | 輸入帳號密碼，勾選「我不是機器人」，按「確定登入」 | 提示列變綠色：「登入成功，程式已讀到系統選單」，並列出選單（基本資料、檢測資料…） |
| 3 | 關閉視窗，再雙擊一次 `登入測試.bat` | 不必重新登入，直接是綠色已登入狀態；紀錄出現「沿用上次登入」 |
| 4（選做） | 按「清除登入資料」，改勾「使用驗證碼登入」再登入一次 | 圖片驗證碼方式也能登入 |

若步驟 2 的「我不是機器人」一直跳出圖片題、或無法通過，請改用步驟 4 的「使用驗證碼登入」。

## 測完請回傳

1. 按「開啟日誌資料夾」，把 `log` 資料夾裡的 `login-test-*.log` 傳給我（內容只有網址路徑、頁面狀態與版本，不含帳密）。
2. 告訴我：
   - reCAPTCHA 是直接勾選就過，還是有跳圖片題？
   - 關閉再開啟，是否維持登入？
   - 若有失敗，畫面看到什麼（可截圖）。

## 說明

- 登入資料（Cookie）存在程式資料夾旁的 `browser-profile`，只在這台電腦上。不要把這個資料夾傳給別人；要登出可按「清除登入資料」或直接刪除該資料夾。
- 內嵌瀏覽器是 Chromium 134（PySide6 6.10 內建）。
- 這個測試只開啟網頁與判讀狀態，不會修改網站上的任何資料。
