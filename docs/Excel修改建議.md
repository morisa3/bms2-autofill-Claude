# 劣化維修規則 Excel 修改建議

建議版檔案：[`docs/excel/劣化說明與維修單價1111v2-建議版.xlsx`](excel/劣化說明與維修單價1111v2-建議版.xlsx)
轉換程式：`tools/excel_v2.py`（可重複執行，1111v1 更新後重新轉換即可）

## 為什麼要改

1111v1 的「備註」欄用自然語言寫條件，493 筆規則有 106 種寫法，例如：

- `有關鍵字[碎裂]或[破碎]與[鋼筋外露]即可使用`：「或」和「與」誰先算，要靠程式猜。
- `裂縫寬度大於[0.3mm]使用`：剛好 0.3mm 歸哪一筆，原文沒說，v0.9.7.6 曾為此出過問題。
- `讀取到護欄高度大於0.85小於1.10時使用`：兩端都不含等於，0.85m 剛好會兩筆都不符合。

另外有些規則根本不在 Excel，而是寫死在程式裡。例如 v1.00 `alignment.py` 規定木本／草本、齒型／角鋼、AC／混凝土不可互相配對，要新增一組就得改程式。

## 改法：原欄位不動，只往右加、往後加

| 改動 | 內容 |
|---|---|
| 原本 7 欄 | 一字不改。舊版助手 v1.00 依表頭讀取、略過不認得的工作表，所以新檔 v1.00 照樣能用（已用程式驗證兩者讀到的 467 筆規則完全相同） |
| 各構件工作表右側新增 17 欄 | 把「備註」拆成固定欄位：處理方式、任一關鍵字、必要關鍵字、排除關鍵字、前置判讀、條件欄位、最小值、最大值、條件單位、單獨關鍵字、單獨關鍵字U值、前期關鍵字、優先序、修正劣化類型為、備註範本、轉換狀態、轉換說明 |
| 檔尾新增 9 張工作表 | 樣態同義詞、互斥樣態、劣化類型等價、位置代碼對照、構件分類、意見U值、意見排除清單、意見構件名稱、參數 |
| 檔首新增「說明」 | 改了什麼、顏色意義、確認順序、寫法規則、各工作表轉換統計 |

## 原備註如何對應到新欄位

| 原寫法 | 新欄位 |
|---|---|
| `有關鍵字[A]或[B]即可使用` | 任一關鍵字＝A、B |
| `有關鍵字[A]與[B]即可使用` | 必要關鍵字＝A、B |
| `有關鍵字[A]或[B]與[C]即可使用` | 任一關鍵字＝A、B；必要關鍵字＝C |
| `裂縫寬度大於[0.3mm]使用` | 條件欄位＝裂縫寬度；最小值＝0.3（含等於）；條件單位＝mm |
| `先判讀是否為[齒型]，再判讀關鍵字[變形]` | 前置判讀＝齒型；任一關鍵字＝變形 |
| `或僅有關鍵字[植生]時，若U值為2優先使用` | 單獨關鍵字＝植生；單獨關鍵字U值＝2 |
| `若過去資料為[AC老化]，則優先使用` | 前期關鍵字＝AC老化；優先序＝1 |
| `但劣化類型填成[其他損傷]，則修正成[防撞鋼板損傷]` | 修正劣化類型為＝防撞鋼板損傷 |
| `手動處理` | 處理方式＝手動 |

數值條件統一為：**最小值含等於（≧），最大值不含（＜）**，相鄰區間不會重疊或漏接。

## 轉換結果

| 項目 | 筆數 |
|---|---|
| 規則總數 | 493 |
| 完整自動轉換 | 488 |
| 需確認 | 5 |

需確認的 5 筆：

| 規則 | 原因 |
|---|---|
| 1-05、14-36 路面坑洞 | 「傷及混凝土層（RC 層）」無法從備註文字判斷，需決定判斷方式或補排除關鍵字 |
| 2-40、2-41、2-42 護欄高度不足 | 原文兩端都不含等於，需確認 0.30／0.60／0.85m 剛好時歸哪一筆 |

## 需要你填寫或確認的地方（黃底、綠底）

1. **各構件工作表**：用「轉換狀態」篩選「需確認」，處理後改成「已確認」。
2. **構件分類**：每個構件填「主構件」「可能影響行車安全」（U＝2 寫持續追蹤或三年內的依據）。
3. **參數**：填「大面積門檻」（平方公尺）。
4. **劣化類型等價**：補上實務上視為同一筆的劣化類型（需求 2.1）。
5. **綠底草稿**：樣態同義詞、互斥樣態、位置代碼對照、意見排除清單、意見構件名稱，內容來自需求說明、v1.00 程式與修正紀錄、竹子坑橋比對結果，請確認。

## 之後的流程

你確認完回傳後，新版程式會改讀這些結構化欄位，不再解析「備註」文字。「備註」欄保留作為人看的說明，舊版 v1.00 也仍以它運作。
