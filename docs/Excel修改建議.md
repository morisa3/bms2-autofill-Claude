# 劣化維修規則 Excel 修改建議

建議版檔案：[`docs/excel/劣化說明與維修單價1111v2-建議版.xlsx`](excel/劣化說明與維修單價1111v2-建議版.xlsx)
轉換程式：`tools/excel_v2.py`（可重複執行，1111v1 更新後重新轉換即可）

## 為什麼要改

1111v1 的「備註」欄用自然語言寫條件，493 筆規則有 106 種寫法，例如：

- `有關鍵字[碎裂]或[破碎]與[鋼筋外露]即可使用`：「或」和「與」誰先算，要靠程式猜。
- `裂縫寬度大於[0.3mm]使用`：剛好 0.3mm 歸哪一筆，原文沒說，v0.9.7.6 曾為此出過問題。
- `讀取到護欄高度大於0.85小於1.10時使用`：兩端都不含等於，0.85m 剛好會兩筆都不符合。

另外有些規則根本不在 Excel，而是寫死在程式裡。例如 v1.00 `alignment.py` 規定木本／草本、齒型／角鋼、AC／混凝土不可互相配對，要新增一組就得改程式。

## 改法：原欄位不動，只往右加、往後加

| 改動 | 內容 |
|---|---|
| 原本 7 欄 | 保留劣化類型、劣化樣態、維修工法、維修單位、單價、劣化ID；「備註」已改由結構化欄位取代（見文末 2026-11-15 版面整理） |
| 各構件工作表右側新增 17 欄 | 把「備註」拆成固定欄位：處理方式、任一關鍵字、必要關鍵字、排除關鍵字、前置判讀、條件欄位、最小值、最大值、條件單位、單獨關鍵字、單獨關鍵字U值、前期關鍵字、優先序、修正劣化類型為、備註範本、轉換狀態、轉換說明 |
| 檔尾新增 11 張工作表 | 樣態同義詞、互斥樣態、劣化類型等價、位置代碼對照、構件分類、DERU評等、意見U值、意見排除清單、意見構件名稱、參數、修訂紀錄 |
| 檔首新增「說明」 | 改了什麼、顏色意義、確認順序、寫法規則、各工作表轉換統計 |

## 原備註如何對應到新欄位

| 原寫法 | 新欄位 |
|---|---|
| `有關鍵字[A]或[B]即可使用` | 任一關鍵字＝A、B |
| `有關鍵字[A]與[B]即可使用` | 必要關鍵字＝A、B |
| `有關鍵字[A]或[B]與[C]即可使用` | 任一關鍵字＝A、B；必要關鍵字＝C |
| `裂縫寬度大於[0.3mm]使用` | 條件欄位＝裂縫寬度；最小值＝0.3（含等於）；條件單位＝mm |
| `先判讀是否為[齒型]，再判讀關鍵字[變形]` | 前置判讀＝齒型；任一關鍵字＝變形 |
| `或僅有關鍵字[植生]時，若U值為2優先使用` | 單獨關鍵字＝植生；單獨關鍵字U值＝2 |
| `若過去資料為[AC老化]，則優先使用` | 前期關鍵字＝AC老化；優先序＝1 |
| `但劣化類型填成[其他損傷]，則修正成[防撞鋼板損傷]` | 修正劣化類型為＝防撞鋼板損傷 |
| `手動處理` | 處理方式＝手動 |

數值條件統一為：**最小值含等於（≧），最大值不含（＜）**，相鄰區間不會重疊或漏接。

## 需要你填寫或確認的地方（黃底、綠底）

1. **構件分類**：已依《橋梁檢測手冊》第四章分類；主梁、橫隔梁為手冊明訂，其餘為綠底草稿，請確認。
2. **參數**：大面積改以 E≧3 判定；確認主梁寬度、懸臂版寬度、墩柱面積係數等經驗數據。

4. **綠底草稿**：樣態同義詞、互斥樣態、位置代碼對照、意見排除清單、意見構件名稱，內容來自需求說明、v1.00 程式與修正紀錄、竹子坑橋比對結果，請確認。

## 2026-11-15 版面整理：刪除原「備註」

依使用者要求，各規則工作表改成：

- **刪除原「備註」與「轉換狀態」**，判讀方式直接看後面的藍色結構化欄位；原轉換說明改放在「說明」欄（需確認的列為黃底）。
- **劣化ID 保留**，移到最後一欄（程式以它對應規則，修訂紀錄也用它）。
- 欄寬縮小；每格最多兩行、自動換行、垂直置中、靠左對齊。

新版程式以 `bridgefill/core/rules_v2.py` 讀取：由結構化欄位還原成 v1.00 標準寫法，交給已驗證的判斷程式，
所以判讀結果與舊備註一致（`tests/test_rules_v2.py` 逐筆比對 528 筆規則在各種護欄高度、U 值、裂縫寬度、
伸縮縫／支承型式下的結果）。只有 5 筆不同，都是舊備註把說明文字誤當關鍵字：

| 劣化ID | 舊備註多出的「關鍵字」 |
|---|---|
| 1-06、1-07、1-08 | `依照[單位]套用工法與單價` 的 [單位] |
| 5-04 | `在基礎前補上[橋台]或[橋墩]` 的 [橋台]、[橋墩]（描述有「橋台」就會誤配到掏空） |
| 14-39 | `則優先填寫[AC剝離]` 的 [AC剝離]（本列樣態即 AC剝離，仍以樣態配對） |

**注意：沒有「備註」欄後，舊版 v1.00 讀不到判讀條件，v1.00 請繼續使用 1111v1。**

## 2026-11-15 新增：跨構件對應

新增「跨構件對應」工作表（綠底草稿）：同一筆缺失前後期可能記在不同構件（例：前期記在河道的掛淤，本期拆到橋墩基礎）。
配對後剩下的疑似漏建與新增，若分屬相關構件、樣態相同、位置代碼吻合，主程式會提示「可能對應（位置變更）」，
並在「改配對」清單中排在其他構件的最前面；只提示、不自動配對。請確認構件組合與適用樣態關鍵字。
